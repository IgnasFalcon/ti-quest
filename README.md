# ti-quest
**A simple RPG game for the TI-84 Plus CE**

Note: This is an unofficial fan-made calculator port inspired by [*Pocket Quest by Freckled Fox*](https://ko-fi.com/album/Pocket-Quest-J3J55AN6F) and not affiliated with or endorsed by Freckled Fox.

## How to upload to your calculator:
  * [Download TI Connect™ CE Software](https://education.ti.com/download/en/ed-tech/CA9C74CAD02440A69FDC7189D7E1B6C2/EE9E51FA137C4F388252DD191CAB37BF/TIConnectCE-6.0.3.619.exe).
  * Open software.
  * Connect the calculator via a mini usb-b cable.
  * Drag and drop the [TIQUEST.8xp](https://github.com/IgnasFalcon/ti-quest/raw/refs/heads/main/TIQUEST.8xp) file from the [latest release](https://github.com/IgnasFalcon/ti-quest/releases/latest) to connected calculator pop-up.

## Running the program:
  * Go to your calculator and press the "**PRGM**" button.
  * Scroll down to "TIQUEST" using the arrow buttons.
  * Press "**ENTER**" to select the program.
  * Press "**ENTER**" again to run it.

## Playing the game:
  * [Watch the original tutorial](https://youtu.be/yzcg7YWqKao?si=P3K1hOXZ8YB4T4Xv) by *Freckled Fox*.
    **Note that this game is the similar to the original other than these differences:**
    * Move your character [**x**] using the buttons **8**, **4**, **2**, and **6** on the number pad.
    * Press "**CLEAR**" to quit.
    * Press the blue "**2nd**" button to continue to next day.
    * Pixie dust lets you time-travel instead of teleporting.
    * There is neither a telescope nor a love potion in this game.
    * You get infinite inventory.
    * You can shop for all items at the same time.
    * To use a bomb, use it before walking into an obstacle.
    * Each armor upgrade reduces the damage given to you by monsters by one.
    * Each level of sharpness increases your attack damage by one.
    * Use the left and right arrow keys to cycle between the map, backpack, and allies menus.
    * Use the up and down arrow keys to cycle between lines in backpack, and allies menus.
    * Press "**DEL**" in the allies menu to abandon the selected ally.
  ### KEY:
  ```
    [+] → Attack  
    [F] → Food  
    [♡] → Woo  
    [⁎] → Health  
    [A] → Treasure  
    [π] → Shop  
    [θ] → Monster  
    [⁎] → Ally  
    [0] → Obstacle  
```
